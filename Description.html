🎮 About the Game

Erebor is a web-based social deduction game where players take on the roles of Developers or Hackers. The Developers must identify and eliminate the Hackers before the system crashes. With special roles like Debugger who debugs and Cyber-Guardian, each game is a strategic battle of deception and deduction!

🕹️ How to Play

At the start of the game, players are randomly assigned roles. The game progresses through a continuous cycle of:
three key phases
1. Development Phase – All players actively write and submit code.

2. Sabotage Phase – The Hacker attempts to manipulate the code under the guise of debugging, the Debugger works to decode and fix potential issues, and the Cyber-Guardian monitors for suspicious activity.

3. Iteration Phase – The process repeats, with players adapting their strategies based on previous actions and discoveries. This structured cycle challenges players to balance efficiency, vigilance, and deception as they navigate an environment of continuous coding and hidden sabotage.

🎭 Roles

Developer 👨‍💻 - Fixes code and eliminates Hackers before they take over.
Hacker 🕵️‍♂️ - Sabotages the system by bugging the code. Wins if the Developers fail to find them.
Debugger 🛠 - Can repair corrupted code once per round.
Cyber Guardian 🚨 - Investigates one player per round to detect Hackers.

🔄 Game Phases

1️⃣ Coding & Sabotage
- All Players answer a coding question.
- The Hacker selects a target to debug.
2️⃣ Actions & Investigations
- Debugger 🛠 attempts to fix corrupted code.
- Cyber Guardian 🚨 investigates one player.
- Developer 👨‍💻 continue their coding tasks.
3️⃣ Discussion & Voting
- Players discuss their suspicions.
- Everyone votes to eliminate a player.
- If a Hacker is voted out, the Developers win. If not, the cycle continues.
